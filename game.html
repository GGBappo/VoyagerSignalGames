Prototype Progress

Making each mission playable.

The current prototype brings together a countdown, strikes for mistakes, wire interactions, and tools that interact with bomb components. Side tasks pay into the player’s budget, which can be spent on tools in the shop.

We’re continuing to build new bomb modules and tools while refining how the interface responds during a mission.
